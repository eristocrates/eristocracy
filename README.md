# the eristocracy

> _“What even is a website?”_

So far (for me at least) my website is to be a **configurable, personalizable, modular, navigable system** for fulfilling **purpose-driven communication**, composed of **structured content**, expressed through **UI components**, designed for **human/computer interaction**

```
 purpose governs affordances

 structure signals meaning
```

Interpreted from **W3C**, **MDN**, and **Information Architecture** traditions, a minimal viable model of a “website” consists of the following semantically stacked layers:

## **teleological system**

> _“Why does this website exist?”_

- Communicate
  - to friends
  - to machines
- Display
  - mirrors of data in ways most suitable for my cognition
  - my ideosyncratic cognitive style
- Connect
  - to those with shared interests
  - to those who have been as lost as I
- Store / retrieve
  - information as prosthetic memory
  - absolutely nothing a user of this site doesn't want stored

---

## **semantic payload**

> _“What data or knowledge does this website hold?”_

- Text
  - maybe a personal blog?
- Images
  - i'd love to showcase the artistry gifts of my friends
- Media
  - mirrors of what I wish to preserve
- Structured data (e.g. RDF, JSON-LD)
  - a wholly unique personal approach to ontology engineering

---

## **information architecture**

> _“How is content organized?”_

- Pages
- Sections
- Links
- Sitemaps
- Graphs

---

#### 🧱 4. **Component Layer**
